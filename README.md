# Algorithmic Thinking Fundamentals  
**Unit 21–25 – Summative Assessment**

## Overview
This assessment evaluates your ability to work with:
- Variables  
- Arrays  
- Sorting  
- Conditional logic  
- Loops  

## Task Requirements

### 1️. Algorithm (Pseudocode or Steps)
Write an algorithm that:
- Creates **three variables**  
- One must be an **array of exactly 10 numbers**  
- Sorts the array smallest → largest  
- Uses an **if-statement** to check EVEN/ODD  
- Displays the result  

### 2️. Code Implementation
Your program must:
- Create the same 3 variables  
- Use this array:  
  `5, 6, 2, 8, 4, 11, 1, 9, 7, 3`  
- Sort it  
- Use an if-statement to check even/odd  
- Print results like:  
```
5: Odd
6: Even
```
- Include comments
